# 用浏览器连接 BMI323 网关

使用桌面版 Chrome 或 Edge 打开 [`index.html`](index.html)，连接网关 USB 数据口，点击“连接网关”，首次选择 **BMI323 Gateway**。
macOS 在项目根目录可运行：

```sh
open -a "Microsoft Edge" "web/index.html"
```

这是可离线使用的独立 HTML，无运行时依赖，无需 Python、Node、网络或本地服务。
打开页面后，若浏览器不支持串口连接，页面会提示切换浏览器。
若串口无法打开，退出占用 `/dev/cu.usbmodemBMIGW0011` 的终端或其他采集程序后重试。

## 停止或恢复节点采集

连接网关，等待「采集会话」出现节点并选中。节点 v1.5 起上电默认待机，收到心跳时样本数仍为 0。点击「恢复采集」启动，在节点下一次心跳时下发命令。
点击「停止采集」后，节点继续上报状态，已有缓存仍可查看和导出。页面收到节点的停采确认后显示「已停止采集」，
收到恢复后的新样本才显示「已恢复采集」。

v1.6 起节点静置后自动休眠。收到所选节点的休眠状态时，页面弹窗提示晃动，关闭后顶部仍显示休眠。晃动唤醒后继续在同一个 `boot_id` 会话采集。正在查看的节点如果发生重启，页面会切到新 `boot_id` 继续接收，旧会话仍可查看和导出。休眠期间没有心跳，新打开页面需等节点唤醒才能发现它。无效温度显示为「— °C」。

如果等待超时，网关可能在节点重新上线后才送达命令。等待期间可以切换并操作其他在线节点。

## 观察与分析

- 连接自动置 DTR，以 115200 配置 CDC，并发送 GET_INFO、每秒 TIME_REQ。节点配置和 Flash 不会被更改。
- 节点按 `node_id / boot_id` 独立显示；DATA/STATUS 按序号去重，POLL 不占序号。新 boot 首次收到样本时自动选中。
- 横轴默认显示**北京时间（UTC+8）**与完整采样日期，可切换为节点时钟、距最新样本时间。北京时间按电脑时钟对齐估算，包含传输延迟，绝对精度尚未标定；与电脑设置的显示时区无关。
- 单击波形放置黄色定位线，图上方显示所选时刻。左键拖动平移，滚轮以所指时刻为中心缩放。按住 `Shift` 再拖动左键会标出蓝色选区，松手放大，`Esc` 取消。单击定位或放大选区后，波形停留在所选时间，数据仍持续接收。点击「回到最新」恢复跟随。
- 「显示范围」保留 250 ms、1/3/10/30 s、1/5/10 min、自定义 0.05～3,600 s 和「全部趋势」。聚焦波形后可用 `+` / `−` 缩放、左右方向键平移、`Home` 回到最新。
- 原始波形保留 96,000 点；较早的数据以每秒最小值/最大值展示，趋势最多保留最近 1 小时。每轴 Welford 桶另存 DC、AC RMS、AC 峰值、CF 和计数，与面板窗口独立；RMS 趋势图留待 M3。支持自动/固定纵轴和三轴开关；原始曲线在缺口、采样配置或连续段变化时断开，趋势桶分别绘制。
- “导出 CSV”导出所选会话的最新原始缓存。
- 在“时域统计”选择 1/2/5/10 s（默认 2 s），只取最近连续段。直流/重力单列，振动（AC）显示同窗口的振动 RMS、波峰因数、振动峰值和峰峰值。g 固定 4 位小数，CF 固定 1 位；零 RMS 显示 `—`，极小正 RMS 显示 `<0.1 mg`。
- 统计面板常驻实际连续点数、窗口时长和近 60 s 缺样率；不足目标窗口时标注实际时长，缺样 >5% 显示 `⚠` 并降灰。
- 振动频谱默认叠加 X、Y、Z 三轴，三条曲线共用频率和幅度坐标。点击 `X`、`Y`、`Z` 可独立隐藏或显示曲线，表中保留各轴主频和峰值幅度。
- 三轴频谱使用同一连续段和采样配置，取最近不超过 4,096 点的最大 2 次幂后缀，去均值后加 Hann 窗，按窗相干增益校正单边峰值幅度。主频为最大非 DC 谱线中心，分辨率为 `采样率 / FFT 点数`。
- 右上角的明暗按钮切换浅色/深色主题，选择保存在本机；未手动选择时跟随系统配色。波形、频谱和三维模型会同步换色。
- 姿态面板把加速度方向解算为重力朝向：X、Y、Z 轴绑定在三维传感器模型上实时旋转。读数给出 X/Y 轴相对水平面的仰角、Z 轴相对竖直方向的倾角与合加速度；拖动模型可变换观察角度，双击复位。加速度含明显运动分量时标记为运动干扰，样本停更或断开后保留最后姿态。仅有加速度时偏航角不可观测。

## 数字的含义

采样率是节点配置值。**节点时钟**使用 DATA 的 `anchor_idx / anchor_us` 计算，每包样本按配置采样率从锚点内插，保留停顿和实际 RTC 进度，并按包序展开 RTC 日回绕或 µs 的 u32 回绕。
首次连接前完整的天数/时钟周期没有在线字段，节点时钟保留这一不确定性。原 `relative_time_s` 仍以本页首个收到的样本为原点，保留原有语义。

**北京时间估算**将节点采样时钟按本页收到的新鲜样本与电脑时钟对齐，积压包在新鲜帧到达后回到对应的历史位置，随后按节点时间推进；显示与 CSV 固定为 `UTC+8`。
此版本没有完成协议手册中的三级时钟标定，时间精度受电脑校时和 RF/USB 延迟影响。
已收样本为本页当前节点/boot 累计收到的唯一点数；“接收区间缺样”是首末已收样本编号之间尚未补齐的缺口，迟到包会减少该数。
连接后网关可能先转发同一 boot 的旧缓存，因此这个区间可能包含连接前的长断链。

FIFO/缓存丢样的 `+` 值从本页该会话首个 STATUS 累计值起算；同一区域另列节点上电以来累计值。
累计值可能很大，即使当前稳定接收也不会归零。主机 CRC/格式错误与网关 RF 错误分别显示。

统计面板的缺样率按主机观测的近 60 s 计算：`missing / (missing + received)`，missing 取 DATA 采样编号缺口（迟到补包回减）和 STATUS 的 FIFO/缓存丢样增量之和中的较大值。STATUS 首包只立基线，无观测时显示 `—`。AC RMS 为 Welford 总体标准差，振动峰值为 `max|x−mean|`，CF 为 AC 峰值 / AC RMS，纯直流时 CF 无值。本次 M1 不包含速度、频段能量或底噪标定。

每会话滚动保留 96,000 原始点和最近 1 小时的每秒极值，最多保留最近发现的 4 个会话；超限会淘汰更早且未选中的会话。高频分段时，趋势另有 4,096 桶上限，实际范围显示在波形下方。
CSV 是当前**原始缓存**快照，包含展开/原始采样编号、原有相对时间、boot、segment、配置、包序号、连续性标志，以及三轴原始 LSB 与 g 值；新增 `node_time_s`、`beijing_time_estimate`（带 `+08:00`）、`node_clock_raw`、`node_clock_unit`。
时域统计与 FFT 始终使用原始连续样本，较早的极值趋势不参与分析。未导出的缓存与趋势会在关闭或刷新时丢失。历史 `data/` 文件保持原样。

## 开发与验证

页面已包含全部 CSS/JS，修改源文件后在项目根目录重新生成：

```sh
make web
make test-web
```

`build.cjs` 只用 Node 标准库，将 `client.template.html`、`src/style.css`、`src/app.js`、
`src/analysis.js`、`src/timeline.js`、`src/attitude.js` 和 `js/protocol.js` 内联为 `index.html`。协议、计算、时间/趋势与姿态模块也可用 CommonJS 单独测试。
不需 npm 安装。协议偏移依据 `firmware/common/proto.h` 和 `docs/02_无线协议.md`。

`make test-web` 在 Node 中运行协议、计算、时间轴与姿态解算单元测试。需要检查页面交互时，用 Edge 打开生成的 HTML。

历史实测记录见 `build/web-gateway-live.csv`、`build/web-gateway-live.png`（本地诊断产物，`build/` 不入库）和 [M1 实施记录](../docs/12_上位机振动指标改造方案.md#11-实施记录)。
