连接与分析

  1. 用 Chrome 或 Edge 打开这个 HTML，连接网关 USB 数据口。
  2. 点击“连接网关”，在串口列表里选择 BMI323 Gateway；页面会自动设置 DTR 并接收。
  3. 默认显示北京时间（UTC+8）。节点采样时钟按电脑接收时间对齐，包含传输延迟，绝对时间精度尚未标定。
  4. 单击波形放置定位线，图上方显示所选时刻。左键拖动平移，滚轮以鼠标所在时刻为中心缩放。按住 Shift 再用左键拖动会标出蓝色选区，松开鼠标放大选区，按 Esc 取消。点击“回到最新”恢复跟随，节点采集继续进行。
  5. CSV 导出当前会话的原始缓存，最多 96,000 点，包含节点秒数、北京时间估算和原有相对时间。

节点时钟使用 DATA 中的真实锚点；首次连接前完整的 RTC 天数/时钟周期无法由协议确定。按节点和 boot 分开查看。缺口或分段处断开曲线；频谱始终只分析最近连续段的原始样本，最多 4,096 点。

STATUS 丢样从本次首个状态包起算。关闭或刷新页面会丢失未导出的缓存与趋势。

右上角按钮切换明暗主题，选择会保存在本机。姿态面板只由加速度方向估计重力朝向，X/Y/Z 轴绑定在模型上随时间旋转；偏航角无法由加速度确定。拖动模型可变换视角，双击恢复。

如果串口无法打开，请退出占用串口的程序，确认设备正常上电后重试。
