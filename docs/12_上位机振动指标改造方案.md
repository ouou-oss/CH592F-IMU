# 上位机振动指标改造方案（RMS 口径修正与趋势化）

**状态**：M1 已完成（M1-1～M1-6；M2/M3 待实施）
**适用对象**：网页观测台（`web/index.html`）
**目标读者**：实施者（codex）。本文给出指标定义、改动位置、验收标准与明确的非目标。

---

## 1. 一句话目标

把"能看到的数字"变成"能用来判断设备好坏的指标"：**AC RMS 成为唯一振动幅值，每秒一个 RMS 进入历史，每个数字都带有效性与单位。**

---

## 2. 背景与现状（为什么现在这套指标不能用）

### 2.1 实测证据（2026-11-19 现场截图，节点 1，3 200 Hz，±16 g）

| 轴 | 均值 | RMS | AC RMS | 峰值 | 峰峰值 |
|---|---|---|---|---|---|
| X | −0.2214 | 0.2354 | 0.0038 | 0.2354 | 0.0259 |
| Y | −0.0509 | 0.0510 | 0.0035 | 0.0620 | 0.0234 |
| Z | 0.9619 | 0.9619 | 0.0038 | 0.9751 | 0.0298 |

同时：已收 520 059 点、缺样 17 430 点（**3.35%**，2 个采样段）、缓存丢样 +17 955、FFT 主频 7.81 Hz / 0.0007 g、电池 0 mV、串口一度 `Device not configured`。

### 2.2 从这组数能读出的事实

1. `RMS ≈ |均值|`（Z 轴 0.9619 vs 0.9619，差在第 5 位小数）。总 RMS 被 1 g 重力和安装零偏支配，**作为振动指标无效**。
2. 三轴 AC RMS 全部 0.0038 g 量级且几乎相同 → 这是**传感器白噪声底**，不是振动。
3. `峰值` 列同样是 `max|x|`（含直流），Z 轴 0.9751 无意义；只有 `峰峰值` 天然去直流。
4. 波峰因数 ≈ 0.014 / 0.0038 ≈ **3.7**，与 4 096 点高斯噪声理论值（3.5～3.9）吻合 → **CF 3.x 不能作为绝对告警阈值**，必须配噪声底基线。
5. 0.78 Hz 分辨率下"主频 7.81 Hz"是低频漂移残留（白噪声单 bin 应约 1.2e-4 g，实测高约 6 倍），UI 直接标"主频"会误导。

### 2.3 当前实现

网页观测台提供去直流振动统计、连续段窗口和每秒趋势桶。速度 RMS、频段能量与趋势导出留待 M2/M3。实现位置和验收标准见 §4。

### 2.4 场景约束（决定不能照抄标准）

传感器装在**料架上随线移动**（15 台料架 × 左右各 1 节点，150 m 线体），属**低速移动设备**，不是固定式旋转机械。因此：

- ISO 20816 的 10–1000 Hz、mm/s RMS、A/B/C/D 分区**只能作参考**，频带需可配（默认 10–1000 Hz，另供 2–500 Hz）；
- 主判据应当是**自建基线 + 相对趋势**，而趋势现在不存在（见 2.3）；
- 与节点模式 B 的 SUMMARY 字段（`rms_x/y/z` mg、`max/min`、`trig_cnt`）必须口径一致，否则模式 A/B 数据不可比。

## 3. 指标口径定义（实施必须逐条照做）

> 所有统计一律基于 **AC（去直流）** 分量。记某轴原始样本为 `x[i]`（单位 g），窗口为 `W`。

### 3.1 基础量

| 名称 | 符号 | 公式 | 单位 | 显示 |
|---|---|---|---|---|
| 直流/重力 | `dc` | `mean(x)`，用 Welford | g | 4 位 |
| 振动 RMS | `aRms` | `sqrt(Σ(x[i]−dc)² / N)` | g | 4 位 |
| 振动峰值 | `aPeak` | `max(|x[i]−dc|)` | g | 4 位 |
| 峰峰值 | `pp` | `max(x) − min(x)`（天然去直流） | g | 4 位 |
| 波峰因数 | `cf` | `aPeak / aRms` | — | 1 位 |

### 3.2 速度换算（谱域，唯一允许的实现方式）

从现有单边**峰值幅度谱** `A[k]`（g，已做 Hann 相干增益校正，见 `web/src/analysis.js`）换算：

```
f_k  = k * binHz
v_k  = A[k] * 9810.0 / (2π * f_k)                    // mm/s 峰值
vRms = sqrt( Σ_{k: fLo ≤ f_k ≤ fHi} v_k² / 2 )
aRmsBand = sqrt( Σ_{k: fLo ≤ f_k ≤ fHi} A[k]² / 2 )  // 同带加速度 RMS，对照用
```

- `fLo` 默认 **10 Hz**，`fHi` 默认 **1000 Hz**；预设 `2–500`（料架低速轮系）、`10–1000`（ISO 参考）、`100–1000`（高频）。
- **禁止**对时域做积分（`∫a dt`）求速度：直流与温漂会被放大，数值必然失真。
- `fLo` 必须 ≥ `3 × binHz`（4 096 点、3 200 Hz 时 `binHz = 0.78 Hz`，即 `fLo ≥ 2.4 Hz`），不足时该预设置灰并提示。
- 速度结果只在 FFT 可用（连续段 ≥ 32 点）时显示，否则显示 `—`，不得回退为 0。

**自检向量**：合成信号 X 轴 100 Hz / 0.16 g
`v_peak = 0.16 × 9810 / (2π×100) = 2.50 mm/s`，`vRms = 1.77 mm/s`。实现结果与之相差 > 2% 视为错误。

### 3.3 频段能量占比

在同一套谱线上，按四段求平方和并归一化到 100%：

```
< 10 Hz | 10–100 Hz | 100–500 Hz | 500–1600 Hz
```

每段值 = `Σ A[k]²/2` 在该段的占比。四段之和必须为 100±0.5%。显示为 4 条横向能量条（整数百分比）。

> 用途：单一 RMS 只回答"多大"，频段占比回答"在哪"，这是诊断入口。

### 3.4 噪声底与有效性

| 名称 | 定义 |
|---|---|
| 底噪 `noiseFloor[axis]` | 用户点击"标定底噪"后采集 10 s，取每轴 `aRms` 的**中位数**并持久化（`UserDefaults`，键含 `node_id`） |
| 信噪比 `snr` | `20·log10(aRms / noiseFloor)`，单位 dB |
| 判定 | `aRms < 1.12 × noiseFloor`（≈ +1 dB）时显示"**无有效振动**"灰态；数值仍显示但降低强调 |
| 缺样率 | 最近 60 s：`missing / (missing + received)`，来源为 STATUS 的 `fifoGapSamples`、`ringDropSamples` 增量 + 包序号缺口 |
| 窗口有效性 | 显示实际参与统计的连续点数、时长（秒）、缺样率；缺样率 > 5% 时整组加 `⚠` 并降灰 |

**任何 RMS 数字旁边必须同时出现：单位、窗口时长、缺样率。** 缺一样即视为未完成。

### 3.5 显示格式（统一）

| 量 | 格式 | 示例 |
|---|---|---|
| g | `%.4f g` | `0.0038 g` |
| mm/s | `%.2f mm/s` | `1.77 mm/s` |
| µm | `%.0f µm` | `142 µm` |
| 波峰因数 | 1 位 | `3.7` |
| 百分比 | 整数 | `71%` |
| 频率 | 2 位 | `100.00 Hz` |
| 大计数 | 千分位 | `520,059` |

低于阈值不得显示为 `0.0000`：`aRms = 0` 显示 `—`；`0 < aRms < 0.0001 g` 显示 `<0.1 mg`。

### 3.6 统计窗口

- 默认 **2 s（6 400 点 @3 200 Hz）**，可选 `1 / 2 / 5 / 10 s`；
- 单次统计内 `aRms`、`aPeak`、`pp`、`cf` **必须同窗口**，不得混用；
- 连续段短于窗口时按实际长度计算并在 UI 标注，例如 `1.28 s（不足 2 s）`；
- FFT 窗口独立，仍取 2 的幂（最大 4 096），UI 同时标出点数与 `Δf`。

## 6. 测试要求

在 `web/tests/` 使用合成信号验证：

1. **直流 + 单音**：`1.0 g + 0.16 g sin(2π·100t)` → `dc = 1.0±1e-6`、`aRms = 0.1131±1%`、`acPeak = 0.16±1%`、`cf = 1.414±1%`、`vRms = 1.77 mm/s ±2%`。
2. **白噪声**：种子固定、σ = 0.0038 g → `aRms ≈ σ ±2%`、`cf ∈ [3.2, 4.2]`（证明不能用绝对 CF 阈值）。
3. **频段占比**：仅 100 Hz 单音 → `10–100` 段 = 100%±0.5%。
4. **趋势桶一致性**：同批样本，桶内 Welford 与直接计算差 < 1e-6。
5. **窗口边界**：连续段 1 000 点、窗口 2 s → 显示实际 0.31 s，数值仍有限。
6. **缺样标注**：人为制造 10% 缺口 → 缺样率 10%±1%，`⚠` 出现。

运行 `make test` 回归。

## 7. 非目标（明确不做）

1. **不再新增"总 RMS"**，已删不回退。
2. **不在节点固件里算 RMS 上传**。模式 A 全量上传、主机计算；节点端 RMS 只服务模式 B（`05_边缘模式与功耗.md` §3），两套实现算力可不同，**但公式与单位必须一致**（mg、去直流）。
3. **不做 ISO 20816 的 A/B/C/D 自动判定**。当前是移动料架，标准阈值不适用；如需，须先积累 ≥ 2 周基线与现场故障样本。
4. **不对时域做速度积分**，不做位移二重积分。
5. **不做包络/解调、阶次跟踪、模态分析**——现有数据精度基础不够（±16 g、3 200 Hz、缺样 3.35%）。
6. **不改协议、不改固件**，本次只动主机端。

## 8. 风险与注意事项

| 风险 | 说明 | 应对 |
|---|---|---|
| 低频漂移污染速度 | 0.2 g 安装零偏在 10 Hz 处可积出 > 1 mm/s 假速度 | 严格从谱线算，`fLo ≥ 10 Hz` 硬切，DC bin 排除 |
| 缺样导致趋势跳变 | 缺样 3.35% 且断成 2 段，跨段统计不可比 | 趋势桶带 `segment`，跨段断线绘制不连线 |
| 量程偏大 | ±16 g 下分辨率 0.488 mg/LSB，噪声 3.8 mg ≈ 8 LSB | 建议硬件侧评估 ±4 g（另开工单，不在本文范围） |
| 窗口变化导致历史不可比 | UI 窗口可切换 | 趋势桶固定 1 s 窗口，与 UI 窗口解耦，UI 标注"趋势按 1 s 桶" |
| 电池 0 mV | 可能未装电池，仅 USB 供电 | 不影响本次，检查器继续显示 |

## 10. 附录

### A. 单位换算

`1 g = 9.81 m/s²`；`v[mm/s] = a[g] × 9810 / (2πf)`；`d[µm] = a[g] × 9810 × 1000 / (2πf)²`。
**三者随频率变化，任何"单位转换器"必须输入频率。**

### B. 速度 RMS 与 ISO 参考（仅参考，非判据）

ISO 20816-1 代表性边界（mm/s RMS，刚性基础）：

| 组别 | A/B | B/C | C/D |
|---|---|---|---|
| I 小型（<15 kW） | 0.71 | 1.8 | 4.5 |
| II 中型（15–75 kW） | 1.4 | 2.8 | 4.5 |
| III 大型（>75 kW） | 2.3 | 4.5 | 7.1 |

料架属移动低速设备，**不建议直接套用**；列出仅为说明为何必须换算 mm/s 才能"和标准说话"。

### C. 与网文结论的对应关系

- "RMS 是能量等效值" → 本方案 `aRms`；
- "峰值/平均值不可靠" → 删除总 RMS，峰值改为 AC 峰值；
- "波峰因数诊断" → 本方案 `cf`，但**加了噪声底门槛**（网文未提，现场会误报）；
- "速度/加速度/位移按频段选" → 谱域速度 + 频段占比；
- "ISO 20816 分区" → 仅作参考（附录 B），不作自动判据。
