# 05 模式 B：边缘检测与功耗

目标：30 个节点长期运行，微光太阳能 + 可充电电池供电，平均电流目标 ≤ 0.3 mA。
采样仍为 3.2 kHz 连续采集，节点端只上传每秒统计值和事件波形。复用 01 的 §1~§3（BMI323、FIFO、样本编号）和 §5~§6（发送队列、确认表、漫游）。

## 1. 运行调度

- 开 `HAL_SLEEP`，TMOS 空闲时由 `CH59x_LowPower()` 进入睡眠（保留 RAM24K + RAM2K），RTC 唤醒。必须装 32.768 kHz 晶振。
- 装了 32K 晶振的板子，两种模式都用 RTC 作时间基准（cfg.b7 = 1），模式切换时不用换时间单位；SysTick 微秒只用于没有 32K 晶振的早期板。
- 主频：唤醒后 HSE 32 MHz，SPI 4 分频 = 8 MHz（≤ 10 MHz），PLL 是否需要开由 codex 实测 RF 库要求后决定（PLL 约 130 µA）。
- POLL_EVT 每 50 ms（80 tick）：FIFO 中约 160 帧（1.28 KB），容量 256 帧，留 1.6 倍余量。
- 启用 DC-DC（`DCDC_ENABLE`），射频和运行电流约减半。

## 2. 节点端检测（全部整数运算）

每轴去直流：`m += (x − m) >> 7`（m 用 Q8 定点，时间常数 128 点 = 40 ms，截止约 4 Hz），`y = x − m`。

1 s 统计窗口（每轴）：Σy²、max(y)、min(y)、超阈次数。窗口结束时算 RMS（整数开方）。

触发：
- `trig = max(|y_x|, |y_y|, |y_z|)`
- 基线 `base_rms`：1 s RMS 的指数平均（α = 1/64，约 1 分钟），事件进行中冻结。
- `trig > max(k × base_rms, abs_min)` 时触发。k 默认 6，abs_min 默认 0.3 g（±16 g 时 614 LSB），由 SET_DETECT 命令下发。
- 阈值先在模式 A 的全量数据上离线回放确定，离线算法应与节点算法逐位一致。

事件采集：
- 预触发缓冲保存最近 64 ms 原始样本（205 点 × 6 B ≈ 1.2 KB）。
- 事件窗口：触发前 50 ms + 触发后 100 ms（480 点）；窗口内再次触发则延长，最长 300 ms（960 点，5.8 KB）。
- 限流：每分钟最多上报 6 个事件（可配置），超出的只计入 SUMMARY 的 `evt_suppressed`。
- 模式 B 流量小，不需要模式 A 的 40 槽缓存，这块 RAM 改作事件缓冲（union），另留 12 槽发送队列。

## 3. SUMMARY 包（type = 0x3，默认每 1 s 一个）

偏移 0~13 同 STATUS（ver_type、node_id、flags、cfg、boot_id、seq、oldest_seq）。

| 偏移 | 类型 | 字段 |
|---|---|---|
| 14 | u32 | win_end_idx（窗口最后一个样本编号） |
| 18 | u32 | anchor_idx |
| 22 | u32 | anchor_us（RTC 计数） |
| 26 | u32 | sync_txdone_us |
| 30 | u8 | sync_seq_lo |
| 31 | u8 | sync_attempt |
| 32 | u16×3 | rms_x/y/z（mg） |
| 38 | i16×3 | max_x/y/z（去直流后，LSB） |
| 44 | i16×3 | min_x/y/z |
| 50 | u8 | trig_cnt |
| 51 | u8 | evt_sent |
| 52 | u8 | evt_suppressed |

STATUS 包在模式 B 下改为每 60 s 一个。

## 4. EVENT 包（type = 0x4）

一个事件拆成多包，每包最多 34 个样本。偏移 0~13 同 STATUS。

| 偏移 | 类型 | 字段 |
|---|---|---|
| 14 | u16 | event_id（本次上电内递增） |
| 16 | u8 | part_idx |
| 17 | u8 | part_cnt |
| 18 | u32 | first_sample_idx |
| 22 | u8 | n_samples（≤ 34） |
| 23 | u8 | trig_axes（b0 X，b1 Y，b2 Z） |
| 24 | u32 | trig_sample_idx |
| 28 | u32 | anchor_idx |
| 32 | u32 | anchor_us |
| 36 | u32 | sync_txdone_us |
| 40 | u8 | sync_seq_lo |
| 41 | u8 | sync_attempt |
| 42 | u8 | cmd_ack |
| 43 | u8 | 保留 |
| 44 | i16×3×n | 原始样本 x, y, z |

480 点的事件约 15 包。每包独立占用 seq，丢失/去重规则与 DATA 相同；服务器按 event_id 拼回完整波形，缺包时标记不完整。

## 5. 盲区缓存

当前硬件没有 SPI Flash，只用 RAM 队列 12 槽。满了先丢最老的 EVENT 包，再把 SUMMARY 合并成每分钟一条，丢弃数量记入计数器。
如果以后加 SPI Flash（如 W25Q32，4 MB，挂 SPI0，独立 CS），可每包写一页，按 4 KB 扇区循环擦写，约可缓存 1000 个事件。

## 6. 功耗预算（估算，必须实测）

| 项目 | 估算平均电流 | 依据 |
|---|---|---|
| BMI323 加速度高性能模式 | 145 µA | 手册（ODR 最大时）；normal 模式（0b100）可能更低，需实测噪声是否可接受 |
| MCU 唤醒开销 | 约 40~50 µA | 每秒 20 次 × 约 1.6 ms（HSE 起振、库唤醒时间 `WAKE_UP_RTC_MAX_TIME`） |
| SPI 读 FIFO | 约 60~70 µA | 每秒 25.6 kB，8 MHz 下约 26 ms/s，DC-DC 下约 2.5 mA |
| 检测运算 | 约 25 µA | 每秒约 30 万周期，32 MHz 下约 9 ms/s |
| 射频 | 约 10~20 µA | 每秒 1 个 SUMMARY + 事件 + 漫游探测 |
| 睡眠底电流 + 能量采集芯片 | 约 3 µA | 手册睡眠 2.5 µA |
| **合计** | **约 0.28~0.31 mA（3.3 V 下约 1 mW）** | |

可选的降耗手段（按收益排序，实测后再决定）：
1. ODR 降到 1.6 kHz（SPI 和运算减半，事件内 8~16 个点），只在可疑时段切回 3.2 kHz。
2. 关掉 FIFO 时间字（帧 6 B，FIFO 容量 106 ms，可每 80 ms 唤醒一次），丢样改用 SysTick/RTC 估算，可靠性略降。
3. SPI DMA 读 FIFO，传输期间 CPU 停在低功耗。
4. SUMMARY 改为每 5 s 一包（内含 5 个 1 s 窗口）。

## 7. 太阳能与能量分级

- 采集芯片：BQ25570（已选定），储能为超级电容（已选定）。超级电容能量有限，停灯时间较长时需按实测功耗核算容量，由硬件方负责。
- 面板尺寸：按 1 mW 负载、室内微光板 500 lux 下约 15 µW/cm²（粗估）计算，需约 70~80 cm²。**先沿线测照度，再定尺寸**。
- 电池按停灯 72 h 设计：0.3 mA × 72 h ≈ 22 mAh（储能部分由硬件方确认）。
- 能量分级（阈值可配置，按储能电压，具体电压值按超级电容和 BQ25570 配置重新确定）：

| 电池电压 | 行为 |
|---|---|
| ≥ 3.3 V | 正常 |
| 3.1~3.3 V | SUMMARY 每 5 s，事件每分钟最多 2 个 |
| 3.0~3.1 V | ODR 1.6 kHz，SUMMARY 每 30 s，不传事件波形（只计数） |
| < 3.0 V | BMI323 挂起，每 60 s 唤醒发一次 STATUS |
