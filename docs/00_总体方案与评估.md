## 1. 已确认的现场条件

## 2. 核心矛盾：30 节点 + 太阳能 与"连续保存原始数据"不能同时满足

- 单节点全量原始流 19.2 kB/s。30 个节点合计 576 kB/s，单个 2.4G 信道的有效吞吐（1M 约 90 kB/s，2M 约 180 kB/s）远远不够。
- 全量流要求 MCU 常开、射频占空比约 23%，平均电流约 12~16 mA，微光太阳能只能提供约 0.3 mA。

因此采用两种工作模式，同一套固件通过下行命令切换：

| | 模式 A：全量原始流 | 模式 B：边缘检测（默认） |
|---|---|---|
| 用途 | 算法开发、故障诊断、少量参考节点 | 30 个节点长期运行 |
| 上传内容 | 每个样本 | 每秒统计特征（连续）+ 事件前后原始波形 |
| 供电 | 电池 | 太阳能 + 可充电电池 |
| 同时运行数量 | 每个信道 1 个 | 不限（共享信道，负载约 5%） |
| 文档 | 01 | 05 |

"连续保存"在两种模式下的含义：
- 模式 A：原始样本连续保存，缺口精确标记。
- 模式 B：统计特征连续保存，每个事件保存完整原始波形；正常运行时段只保留统计值。

**请确认这个取舍。** 如果长期必须对 30 个节点都保存全量原始数据，就只能用有线供电，并在每台料架上加大容量存储再集中卸载，成本和复杂度会高很多。

## 3. 系统架构

```
 料架 1..15，每台左右各 1 个节点（BMI323 + CH592F + 电池/太阳能）
        |  2.4G，节点随料架移动，自动切换到信号最好的网关
        v
 网关 G1(频点 E1)  G2(E2)  G3(E3)  G4(E1) ...   沿线固定安装，相邻网关用不同频点
        |  LAN / TCP（PoE 或 24 V 供电）
        v
 服务器（Python）：原始日志 → 去重/排序/丢失判定 → 时间轴 → 存储
                   → 事件分类 → 位置推算 → 跨料架复现分析 → 查看/报表
```

另设参考区：在问题最集中的线段布置专用接收端（频点 S1/S2），给模式 A 节点用。

## 4. 关键决策

**D1 采集：FIFO 水位中断 + 20 ms 兜底轮询，FIFO 内开传感器时间字。** 见 10 §3.2。

**D2 时间基准：节点统一用 RTC（外部 32.768 kHz 晶振，已有），两种模式相同；网关常开，用 SysTick 微秒。**
内部 LSI 精度约 1000 ppm，不用。

**D3 组网：网关分区用不同频点 + 节点主动切换。** 3 个频点 E1/E2/E3 交替分配给沿线网关，同频网关至少隔 2 个站点，避免两个网关同时回 ACK 互相干扰。
节点连续失败就轮询其他频点，以第一个回 ACK 的网关为准。网关负载低（每个网关覆盖范围内约 5~8 个节点），用随机接入 + 退避。

**D4 可靠传输：硬件 ACK + 确认表。** RF 库的 ACK 内容在收包前就已固定，多节点共享信道时，硬件 ACK 可能被并未成功的另一个节点误收。
所以硬件 ACK 只算"链路层初步成功"；网关在后续 ACK 里携带最近收到的 (node_id, seq) 确认表，节点看到自己的 seq 才释放缓存，见 02 §5。

**D5 去重/排序/时间拟合在服务器端。** 网关无状态，同一包被多个网关收到也能正确合并。

**D6 PHY：模式 B 用 1M（距离优先），模式 A 参考区用 2M。**

**D7 事件检测：模式 B 在节点端做初筛（整数运算的阈值触发），服务器端做分类。** 规则、阈值先在模式 A 的全量数据上调好，再下发到节点。

**D8 位置：网关过站 RSSI 峰值 + 线速插值。** 精度约数米。需要更准时，在轨道已知位置装磁铁，节点加霍尔开关（µA 级）打点，见 03 §2.8。

## 6. 硬件状态

节点板（已确认）：32.768 kHz 晶振已有；启用 DC-DC；BQ25570 + 超级电容；BMI323 INT1 接 PA4；无 SPI Flash。
其他：天线朝向料架外侧，外壳用非金属。可选的霍尔开关位置打点（03 §2.8 方案 P3）留到后续。

网关：CH592F + USB CDC。"带 LAN 的 PCB"若有以太网芯片，请告知型号，后续可以直连车间网络。

## 7. 风险

| 编号 | 风险 | 应对 |
|---|---|---|
| R1 | 沿线覆盖不连续，且没有 Flash，当前盲区最多缓存约 0.175 s（16 槽） | 阶段一先做覆盖测试；按需加网关和漫游 |
| R2 | 微光太阳能供电不足（夜班、周末停灯、漆雾污染面板） | 先测沿线照度；电池容量按停灯 72 h 设计；功耗实测后再定面板尺寸 |
| R3 | 节点端初筛漏检 | 阈值先在模式 A 数据上标定；统计包里带"超阈未上报次数"；可随时切模式 A 复核 |
| R4 | 冲击超过 ±16 g 削顶 | 固件置 CLIP 标志并统计；频繁削顶需换高 g 传感器 |
| R5 | 2.4G 干扰 | 现场扫频选频点，频点可远程修改 |
| R6 | RF 库约束（回调在中断、ACK 预置、RAM 中等待） | 见 01 §6、02 §5 |
| R7 | 26 KB RAM | 缓存槽数按 map 文件实测确定 |
| R8 | BMI323 ODR 偏差 ±1.7% | 时间一律用锚点拟合 |
| R9 | 喷涂区是否属于防爆区 | 仍需确认 |
